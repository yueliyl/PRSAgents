# COMP565 Fall 2026 Course Project: PRSAgents

## Download the complete student package

[**Download PRSAgents_Student_Package.zip (137 MB)**](https://github.com/yueliyl/PRSAgents/releases/download/fall2026-v1/PRSAgents_Student_Package.zip)

The complete project is distributed through [GitHub Releases](https://github.com/yueliyl/PRSAgents/releases). The package includes:

- All 40 simulated datasets and shared Stage 1 data.
- Python scripts, guides, and pinned requirements.
- The complete three-stage project description in PDF and editable Word format.
- Stage 3 instructions for running Qwen locally with Ollama, without a paid subscription or API key.

## Get started

1. Download the student-package ZIP linked above.
2. Unzip it and open the extracted `Student_Package` folder.
3. Read `COMP565_PRSAgents_project_description.pdf` and the included `README.md`.
4. Follow the included setup instructions using Python 3.12 or newer, then run the project from that folder.

Download **PRSAgents_Student_Package.zip** under the release's **Assets**. GitHub's automatically generated **Source code** archives and a clone of this repository do not include the datasets.

The package contains student materials only; test phenotypes, instructor answer keys, and instructor solution reports are withheld.
